## 01 // PROBLEM
Ask any agent for a landing page and you get the same page: a violet gradient, a glowing orb, three equal cards and a "loved by 10,000+ teams" line nobody earned. It looks finished for a second, and the phone layout often scrolls sideways.

I wanted the agent to work like a designer first and a code generator second, without me writing a long prompt every time.

## 02 // APPROACH
- **One command.** `/dent` reads the request, the project and the risk, then chains the right steps: plan, direction, build, verify, score. A bug report goes straight to the fix; a launch gets the full pipeline.
- **Ask, or decide and say why.** It asks the few questions that change the result. If I skip them, it picks and shows its reasons.
- **Name the cliché, then leave it.** A concept sentence, one of 41 styles or a named direction, and a hero built for that concept.
- **Honesty is a gate.** No invented reviews, logos or numbers. Real proof or a clearly marked placeholder.
- **Modern Web Guidance decides how web code is built.** Google Chrome's guidance is bundled and wins conflicts: native `<dialog>`, `popover` and anchor positioning before any library.

## 03 // BUILD
It's a set of Markdown skills and commands, plus Python scripts the agent runs. The plugin installs in Claude Code, Codex, Cursor, Copilot, Gemini CLI and anything else that reads `SKILL.md`.

- **Checks:** `verify_page.py` renders each page at six widths with Playwright and fails on horizontal overflow, low contrast, unlabeled inputs, motion that ignores reduced-motion settings and autoplaying audio.
- **Scoring:** the agent scores its own work against the request, needs evidence for each score, and `/dent:improve` fixes the top three gaps and scores again.
- **Benchmark:** the same prompt built twice by Claude Code on Opus 5.5, once without DENT and once with it, across 8 builds. Average 37.9 without, 43.8 with, out of 50. Every result, deviation and screenshot is in the repo.
- **Website:** a static page on Cloudflare Workers at dent.solarquack.in.
- **The film on this page:** made by DENT itself with `/dent:video` at All-out effort. One `render(t)` function in an HTML page draws every frame, Playwright captures them at 60 fps with real motion blur on the fast moves, and the custom DENT lettering, the music and the sound effects are all made in code. The picture and the score read the same cue sheet, so every hit lands on its frame.

## 04 // LEARNED
- Rules written as prose got ignored in the first benchmark. Turning them into gates inside each command, with a script that fails the build, is what changed the output.
- The biggest lift wasn't looks. All 7 web builds with DENT passed every automated check; all 7 without it failed at least one, and one invented "4.8 · 312 reviews".
- The scores come from the same model family that wrote DENT, so they aren't independent. The README says so, and human reviews are welcome.
