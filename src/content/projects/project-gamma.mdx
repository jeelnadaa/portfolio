## 01 // PROBLEM
TODO: Rendering high-detail marble statue textures created banding artifacts on standard 8-bit displays when dimmed against deep black backdrops.

## 02 // APPROACH
TODO: Implemented an 8x8 Bayer matrix dither algorithm directly in the fragment shader, eliminating color banding while evoking classical dossier print aesthetics.

```glsl
// Bayer ordered dither threshold
float bayerValue = texture(uBayerMap, gl_FragCoord.xy / 8.0).r;
if (luminance < bayerValue) discard;
```
