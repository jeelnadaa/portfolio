## 01 // PROBLEM
Trackers tell you that you lost. They rarely tell you that you died first on the same spot in four of six attack rounds, and most of them are web pages full of ads, or overlays that want an account.

I wanted one small Windows app that keeps every match on my own PC and turns it into things I can act on before the next game.

## 02 // APPROACH
- **Post-match board over the game.** When a match ends, a click-through overlay shows the full scoreboard with ranks, party tags and three short facts about the match, and it shows up on its own.
- **Heatmaps named by callout.** Kills, deaths, opening duels, plants and where rounds end, for me, my team or the enemy, filtered by side, agent and buy type, with hot spots named by the map's own callouts.
- **Comp Advisor that explains itself.** Pick a map, type the teammates' picks, and it suggests only agents I own, each with its reasons: role coverage, my record on that map, and pro pick rates on that map once pro data is published.
- **Honest limits.** It never reads game memory, never scouts during agent select, never unmasks hidden names, and says when a suggestion comes from role coverage only.

## 03 // BUILD
The core is Rust on Tauri v2 with SQLite; the UI is Svelte 5. A request budget keeps background sync under half of the API's per-minute limit, and the API key lives in Windows Credential Manager.

- **Releases:** every push to main builds the installer, an offline installer with WebView2 bundled and a portable zip, writes `SHA256SUMS` and publishes a GitHub release with an automatic version. The installed app updates itself and checks the update's signature first.
- **Advisor data:** a weekly pipeline syncs map callouts and pulls pro pick rates from the LiquipediaDB API (CC-BY-SA), validates them and opens a pull request. Merging it signs the data and publishes it; the app checks once a day, verifies the minisign signature and swaps the data in without a restart.
- **Sources:** I read the terms of every stats site before using it. VLR.gg and Metabot forbid collecting their data, so the pipeline never touches them.
- **Website:** a static site on Cloudflare Workers at postplant.solarquack.in, with a download page that picks the real release assets.
- **The film on this page:** HTML and GSAP rendered frame by frame with HyperFrames, rebuilt from the app's own design files with made-up players, with a neural voice, word-timed subtitles and music written on a 120 BPM grid.

## 04 // LEARNED
- Showing a ranked win rate in the advisor would have looked great, but no source with suitable terms publishes ranked comp statistics. The advisor says so instead of inventing a number.
- Signing the data with the same key as app updates meant one public key in the app and one secret in CI, and a test that verifies a real signed fixture.
- A transparent always-on-top window only shows over the game in borderless windowed mode, so the site says that up front rather than promising an overlay over exclusive full screen.

What isn't done yet: the builds aren't code-signed, so Windows SmartScreen asks once, and pro data switches on once the LiquipediaDB API key is approved.
